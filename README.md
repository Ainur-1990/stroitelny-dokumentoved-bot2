# Строительный Документовед — Telegram-бот

MVP русскоязычного Telegram-бота для строительной компании. Бот принимает документы и сообщения, показывает доступные операции, формирует структурированный отчёт и квалифицирует входящие заявки.

## Что реализовано

- `/start`, `/help`, `/status` и меню кнопок.
- Приём текстовых сообщений, PDF/DOCX/изображений и документов Telegram.
- Демонстрационный режим анализа: бот не выдумывает реквизиты, цены, нормы и объёмы.
- Квалификация лида: объект, площадь, виды работ, бюджет, сроки и контакт.
- Чёткое ограничение: бот готовит черновики, не подписывает документы и не выдаёт юридические заключения.
- Webhook endpoint с проверкой секретного заголовка Telegram.
- Dockerfile, `render.yaml` и `.env.example`.
- Пакет рекламных материалов Reels: `marketing/reels-scripts.md`.

## Важное ограничение MVP

Для реального OCR, RAG по СНиП/СП/ГОСТ, генерации DOCX/XML КС-2/КС-3 и интеграций с CRM/ЭДО нужно подключить хранилище базы знаний, OCR-провайдер и согласовать форматы исходных документов. Текущая версия безопасно собирает входные данные и не делает неподтверждённых расчётов.

## Быстрый запуск локально

```bash
cp .env.example .env
# заполните TELEGRAM_BOT_TOKEN и WEBHOOK_SECRET
pip install -r requirements.txt
python app.py
```

Для локального теста можно использовать polling:

```bash
POLLING_MODE=true python app.py
```

## Постоянный запуск

GitHub хранит исходный код, но не является постоянным сервером для Telegram webhook. Для работы 24/7:

1. Создайте сервис Web Service на Render из этого репозитория или используйте другой хостинг с HTTPS.
2. Добавьте секреты `TELEGRAM_BOT_TOKEN`, `WEBHOOK_SECRET` и `PUBLIC_BASE_URL`.
3. После запуска вызовите:

```bash
curl -X POST "$PUBLIC_BASE_URL/setup-webhook" \
  -H "X-Setup-Secret: $WEBHOOK_SECRET"
```

В `PUBLIC_BASE_URL` должен быть адрес сервиса без завершающего `/`.

## Безопасность

- Токен бота не хранится в Git и не записывается в логи.
- Не отправляйте в чат документы с персональными данными без утверждённых политик доступа и хранения.
- Перед отправкой заказчику специалист должен проверить все черновики.
- Если токен когда-либо попал в открытый доступ, немедленно перевыпустите его через @BotFather.
